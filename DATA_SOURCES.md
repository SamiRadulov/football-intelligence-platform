# Data Sources

## StatsBomb Open Data

- **Source:** https://github.com/statsbomb/open-data
- **Access:** via [statsbombpy](https://github.com/statsbomb/statsbombpy) or a controlled download script; no authentication required.
- **License:** StatsBomb Open Data is provided under the terms of the [StatsBomb Public Data User Agreement](https://github.com/statsbomb/open-data/blob/master/LICENSE.pdf). Use of this data requires attribution to StatsBomb.
- **Attribution:** Data provided by StatsBomb. This project follows the repository user agreement, including logo/attribution requirements when publishing analysis.

## What is (and is not) in this repository

- Raw StatsBomb JSON is downloaded locally into `data/raw/` and is **gitignored** — it is not redistributed here.
- Only a small publishable sample (for tests and app smoke tests) may live in `data/sample/`, within the limits of the source terms.
- No third-party logos or assets are redistributed beyond what the source terms allow.
